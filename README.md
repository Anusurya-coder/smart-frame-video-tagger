# Smart Video Frame Tagger

AI-powered video frame tagging using Grounding DINO.

## Project Workflow

Video Upload
→ Frame Extraction
→ Text Prompt
→ Grounding DINO
→ Object Detection
→ Timestamp + Confidence + Bounding Box
→ JSON / CSV
→ Web UI

## Technology Stack

- Python
- PyTorch
- Grounding DINO
- OpenCV
- FFmpeg
- FastAPI
- React
- Git/GitHub
